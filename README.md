# 📊 Simple Logistic Regression – R ioslides Presentation

This project is an ioslides presentation built in R as part of a class assignment. The topic covered is **simple logistic regression**, demonstrated using R, ggplot2 visualizations, and LaTeX math.

## 📁 Files
- `SimpleLinearRegressionPresentation.Rmd`: R Markdown source file for the ioslides presentation
- `SimpleLinearRegressionPresentation.html`: Rendered ioslides HTML file (uploadable to RPubs)
- `.gitignore`: Excludes common temp and cache files

## 🧠 Presentation Highlights
- Built using R Markdown with `ioslides_presentation`
- Includes:
  - ✅ Explanation of logistic regression and linear model assumptions
  - ✅ Three `ggplot2` plots:
    - Scatterplot with linear fit
    - Residual vs Fitted plot to assess assumptions
    - Histogram of residuals for diagnostic evaluation
  - ✅ One `plotly` plot (interactive linear regression fit)
  - ✅ One slide with working R code (summary output of linear model)
  - ✅ Summary statistics of regression output
  - ✅ Structured visual format suitable for RPubs upload

## 🛠️ Tools & Libraries
- R
- `ggplot2`
- `dplyr`
- `knitr`
- `LaTeX` (for math formatting)
- `rmarkdown` with `ioslides_presentation`
